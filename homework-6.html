EXERCISE 1 · RIEMANN AND LEBESGUE INTEGRATION

Two viewpoints on the same area

An integral adds up area. The two definitions organize that addition differently.

Riemann: cut the x-axis

Divide the input interval into narrow pieces. Sample the function in each piece, then add each height times its piece width.

ΔxΔxΔxΔxΔxΔx
RN = Δx · Σ f(xi*)

Here the sample is the middle of each interval. For a smooth curve, narrower slices usually improve the estimate.

Lebesgue: cut the y-axis

Group input points by the height their function reaches. For each height band, estimate how much input length lands in that band, then add height × length.

∫ f ≈ Σ (height level) · (length of its preimage)

A preimage is the set of x-values whose outputs fall in a chosen band. In this demo, its length is estimated by counting sample points.

Important: this is a finite, Lebesgue-inspired approximation. The true Lebesgue definition uses the measure (length) of each preimage set. The program estimates those lengths from sampled x-values, so it is not an exact symbolic Lebesgue integral.

What the examples show

  • For bounded Riemann-integrable functions, both approximations approach the same integral as the x-grid gets finer and the range bands get narrower.
  • A fixed number of range bands leaves a height-quantization error. More bands reduce that error, but add bookkeeping.
  • With the same N, midpoint Riemann needs about N function evaluations. The range method also bins each output and accumulates B counts: O(N + B).
  • If the preimage lengths are known exactly, a Lebesgue simple-function sum can be efficient. Estimating those preimages can be the hard part.

Special cases need care

1/√x: its range is unbounded, but its improper integral is finite (= 2). The demo uses a finite, sample-dependent top band; the tail is grouped into that last band, so its range estimate can be rough.

sin(x)/x: the formula is undefined at x = 0. We define f(0) = 1 using its continuous limiting value; changing a single point does not change the integral.

Thomae: the integral is 0, but a finite grid samples rational points with positive values. Those values shrink as the reduced denominators grow.

Pathological counterexample — Dirichlet’s function. It is 1 at rational x and 0 at irrational x. Its Lebesgue integral is 0 because the rationals have length zero. It is not Riemann-integrable: every interval contains both kinds of point, so the upper sum stays 1 and the lower sum stays 0. Every midpoint in our regular finite grid is rational, so both sampled estimators misleadingly report 1. This is a lesson about the limits of finite sampling, not a contradiction in integration theory.

EXERCISE 2 · NUMERICAL COMPUTATION OF THE NORMAL CDF

How much of the bell curve lies to the left?

For a standard normal value Z, the cumulative distribution function Φ(z) is the probability that Z is at most z. In area language, it is the area under the bell curve from the far left up to z.

Φ(z) = (1 / √(2π)) ∫−∞z exp(−t² / 2) dt

For example, Φ(1) is about 0.8413: roughly 84 out of 100 standard-normal values are at or below 1. The table below compares three methods against the five-decimal values in NIST’s standard-normal table.

Method A — Simpson’s numerical integration

Use the normal curve’s symmetry: Φ(z) = 0.5 + sign(z) × ∫0|z| φ(t)dt. Simpson’s rule estimates this finite integral by weighing endpoints, odd-indexed points by 4, and even-indexed points by 2.

∫abg(t)dt ≈ (h/3)[g₀ + gₘ + 4Σgodd + 2Σgeven]

With M panels it takes O(M) function evaluations. More panels usually improve accuracy until rounding error becomes relevant.

Method B — integrate the erf power series

Expand exp(−t²/2) as a power series and integrate each term. This gives an infinite series for Φ(z), which the page sums until terms become tiny or a safety limit is reached.

Φ(z) = 1/2 + (1 / √(2π)) Σk=0∞ [ (−1)k z2k+1 / (2k k! (2k+1)) ]

It is accurate for moderate z, but terms can become large and cancel for large |z|. The input is capped at |z| ≤ 8; the page suppresses the direct series beyond |z| = 4 and explains why.

Method C — a fast erf approximation

The error function packages a Gaussian integral. The page uses the compact Abramowitz–Stegun 7.1.26 approximation, requiring a fixed number of arithmetic operations and one exponential evaluation.

Φ(z) = ½ [1 + erf(z / √2)]

This is O(1) work per query. The comparison table shows its difference from NIST’s rounded reference at each listed z.

WHY A SPECIAL FUNCTION APPEARS

Liouville’s theorem, erf, and numerical answers

Elementary functions include familiar finite combinations of powers, roots, exponentials, logarithms, and trigonometric functions. The normal density contains exp(−x²/2). Liouville’s theorem from differential algebra gives a way to prove that its antiderivative cannot be written using only elementary functions.

A short look at how Liouville’s theorem applies

A standard consequence of the theorem says that an elementary antiderivative of exp(−x²) would require a rational function R(x) satisfying R′(x) − 2xR(x) = 1, because the derivative of R(x)exp(−x²) is (R′ − 2xR)exp(−x²). A rational function with a finite pole cannot solve this equation: its derivative would have a stronger pole that the other term cannot cancel. So R would have to be a polynomial. But if R is a nonzero polynomial, −2xR has degree one higher than R′, so their sum cannot equal the constant 1. Therefore no such rational function exists, and the Gaussian integral is not elementary. The normal density reduces to this same integral by rescaling x.

That does not mean the probability is unknown or impossible to calculate. Mathematicians give the needed integral a name: the error function.

erf(u) = (2 / √π) ∫0u exp(−t²)dt
Φ(z) = ½ [1 + erf(z / √2)]

This is an exact analytical representation in terms of a special function. It is not an elementary antiderivative. To get a decimal such as 0.84134, a computer still needs a numerical algorithm, a table, or a built-in implementation of erf.

Takeaway: the three CDF methods should agree to the precision they can support. Simpson improves by adding panels, the series improves by adding terms (until cancellation becomes a problem), and the fast erf formula trades a tiny approximation error for a small, predictable amount of work.
