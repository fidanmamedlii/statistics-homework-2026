# Cryptography & Statistics Homework

This buildless static site contains two educational assignments:

- `dist/homework-1.html` — interactive elliptic-curve multiplication on the toy curve y² = x³ + 7 (mod 17), with point trace, optional animation, and a small descriptive statistical interpretation.
- `dist/homework-2.html` — sourced explanation of the mnemonic-to-Ethereum-address pipeline and the different purposes of its standards and primitives.

The toy curve is not secure and must not be used to protect assets. No mnemonic or wallet secret is collected or processed.
