PUBLIC-KEY CRYPTOGRAPHY · INTERACTIVE EXAMPLE

From a private scalar
to a public point

Elliptic-curve multiplication is quick to compute in one direction: choose a scalar k and calculate Q = kG. Recovering k from Q is the elliptic-curve discrete logarithm problem. This tiny curve makes the arithmetic visible.

Teaching toy only. The curve below is y² = x³ + 7 (mod 17), not Ethereum's real secp256k1 field or generator. Its group has only 18 points, so it provides no cryptographic security.

02 / SEE THE GROUP

Points on the curve

Each dot is a finite point (x, y) satisfying the equation. The orange dot marks the current result; the green dot marks G. Reflection across the x-axis gives the inverse point (x, −y mod 17).

x and y coordinates modulo 17 · the point at infinity is not drawn

Point addition

For P ≠ ±R: m = (y₂ − y₁)/(x₂ − x₁) mod 17
x₃ = m² − x₁ − x₂ mod 17
y₃ = m(x₁ − x₃) − y₁ mod 17

For doubling, use m = 3x₁²/(2y₁) mod 17. A vertical line gives P + (−P) = O. Division means multiplying by the modular inverse; for example, 2⁻¹ ≡ 9 (mod 17).

03 / STATISTICAL EXPLORATION

What the outputs do—and do not—look like

For G = (1, 5), the point has order 9. The eight non-identity outputs for k = 1,…,8 are:

(1,5), (2,10), (5,9), (12,1), (12,16), (5,8), (2,7), (1,12)

The x-values 1, 2, 5, and 12 each occur twice. The eight y-values are all different in this short sequence. Coordinates are constrained by the curve equation, so x and y cannot be sampled independently or treated as unrestricted random integers.

A tiny bit-change comparison

With G = (1,5), k = 6 is 110₂ and gives Q = (5,8); k = 7 is 111₂ and gives Q = (2,7). The input changes by one bit. In fixed-width 5-bit coordinate notation, 7 of the 10 output coordinate bits differ. That is one example, not evidence of an avalanche effect: a toy group is far too small for cryptographic conclusions.

Interpretation

  • Meaningful for the one-way public-key idea: scalar multiplication is deterministic and efficient, while recovering the scalar from a point is the ECDLP. Security depends on using a well-chosen, very large group and suitable parameters—not on this toy experiment looking random.
  • Not a cryptographic hash: multiplication maps into a structured elliptic-curve group, is tied to a base point, and serves to create a public key for signatures. A hash maps arbitrary-length messages to fixed-length digests and is designed for properties such as preimage and collision resistance.
  • Statistics are only descriptive here: the finite, repeated sequence has a strong algebraic structure. A frequency chart or correlation from eight outputs cannot test real-world cryptographic security or establish uniformity.
Optional check: choose G = (6, 6), which has order 18, and compare the longer sequence. The underlying point-addition rules are unchanged; only the subgroup generated by G changes.

METHOD NOTE

How the modular inverse is found

All arithmetic is reduced modulo 17. Since 17 is prime, every nonzero denominator has an inverse. The demo finds that inverse in the finite field, handles point doubling and opposite points, and iterates from G through kG. It does not implement Ethereum key handling, signing, or a production curve library.
